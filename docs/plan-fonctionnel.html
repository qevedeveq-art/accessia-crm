Module Core

7. Automatisation & Scheduler
APScheduler · BackgroundTasks · /api/webhooks
Module Infra
⏰ Jobs toutes les 24h
  • Factures envoyées en retard → tâche relance créée automatiquement
  • Devis expirés (valid_until passé) → status="expire"
  • Récurrents dont next_billing_date ≤ now → facture créée
  • next_billing_date avancée selon fréquence (relativedelta)
🔔 Webhooks temps réel
  • quote.accepted → déclenché à la signature ou changement de statut
  • invoice.paid → déclenché au passage en statut payée
  • Signature HMAC-SHA256 dans X-ACCESSIA-Signature
  • BackgroundTasks FastAPI (non bloquant)
  • Timeout 5s par webhook, erreurs silencieuses
